## The painting on the main page

`src/assets/composition-vii-1913.jpg` — **Wassily Kandinsky, *Composition VII*,
1913**, oil on canvas, State Tretyakov Gallery, Moscow.

* The artist died in 1944, so the work is in the public domain (life + 70
  years, since 2015 in the jurisdictions that count 70 years; published in
  1913, it is public domain in the United States as well).
* The file is a faithful photographic reproduction of a two-dimensional work
  of art, which Wikimedia Commons hosts under the *PD-Art* rule: a
  reproduction of a public-domain 2D work carries no separate copyright.
* Source: <https://commons.wikimedia.org/wiki/File:Vassily_Kandinsky,_1913_-_Composition_7.jpg>
* The file here is the Commons file, stripped of metadata and re-encoded as a
  progressive JPEG (1000 × 657).

Public domain needs no attribution. The site names the painter, the title and
the year anyway, because a name on a painting is how a museum does it and
because the name of the release (2.0, *Composition*) comes from this work
(`docs/release-names.md` of the Micro OS tree).
